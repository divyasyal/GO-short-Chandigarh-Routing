What GO-short gives you

🗺️
Real Map Data

Uses OpenStreetMap roads of Chandigarh — accurate, open and updatable.

⚡
Fast C Backend

Graph loaded in memory and Dijkstra’s algorithm provides instant shortest paths.

🔍
Search & Geocoding

Type place names or click the map to pick start/end. Reverse-geocoding shows readable names.

🚶
Modes & ETA

Walking/cycle/drive modes with ETA calculation; path export and animated display.
